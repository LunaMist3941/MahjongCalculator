# 計算仕様の参照元

このプロジェクトの点数計算は、一般的なリーチ麻雀の四麻ルールを基準に実装する。外部の有料サービスや購入が必要な資料は使用しない。

- [Japanese Mahjong Wiki: Japanese mahjong scoring rules](https://riichi.wiki/index.php?title=Japanese_mahjong_scoring_rules) — 翻・符、満貫以上の区分、基本点 `符 × 2^(2 + 翻)`、ロン／ツモの支払い倍率を確認するための参照。
- [FreeSVG: mahjongtiles](https://freesvg.org/mahjongtiles) — Public Domainの麻雀イラスト候補を確認したページ。実際の牌画像には、より実用的なPublic Domain素材であるFluffyStuffの牌セットを採用した。
- [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles) — `web/public/tiles` に同梱した牌SVGの出典。上流READMEとLICENSEはPublic Domain／CC0を明記している。

## 現在の実装範囲

- 4面子1雀頭、七対子、国士無双の形判定
- Web入力では追加順の14枚目を和了牌として扱い、待ち依存の役判定に利用（純正九蓮宝燈を含む）
- 鳴き面子は順子・刻子・槓子を登録でき、槓子1つにつき物理牌数を1枚増やして検証する
- 立直、ダブル立直、一発、門前清自摸和、海底摸月、河底撈魚、嶺上開花、搶槓、天和、地和、断么九、役牌、平和、一盃口、二盃口、混全帯么九、純全帯么九、混一色、清一色、対々和、三暗刻、三槓子、混老頭、三色同順、三色同刻、一気通貫、小三元、七対子、大三元、四暗刻
- 役満が1つ以上成立した場合は通常役・ドラを廃棄し、役満だけを合算する。国士無双十三面待ち、四暗刻単騎、純正九蓮宝燈、大四喜は倍役満として扱う。
- ドラ、裏ドラ、赤ドラは入力された枚数を加算
- 三麻の北抜きは、雀魂三麻では抜き北1枚を1翻の抜きドラとして加算。一般三麻は統一ルールではないため、採用卓でのみ枚数を入力する方式にする
- ローカル役はWebでルールごとに登録し、計算時に手動選択した役をCoreへ渡して加算。役満を含む場合は通常役・ドラと同じく役満優先で扱う
- 20符／25符／30符以上の基本的な符計算と、満貫・跳満・倍満・三倍満・数え役満・役満の点数区分

北抜き後の補充牌を嶺上開花とするか、抜き北への搶槓、北抜きによる一発・ダブル立直・地和の消滅など、雀魂三麻固有の局面処理は今後拡張する。一般三麻は北抜きの有無、北の手牌使用可否、抜き後の補充・祝儀などが卓ごとに異なるため、別設定として扱う。

北抜きの確認先:

- [雀魂DB・段位戦（三人麻雀）](https://mahjongsoul.club/content/ranked-match?language=zh-hant) — 北抜き、抜きドラ、嶺上開花、抜き北への搶槓など、雀魂三麻の具体的な扱いを確認。
- [三人麻雀の北風牌の扱い（麻雀ローカルルールWiki）](https://w.atwiki.jp/mahjlocal/pages/310.html) — 一般三麻には北抜き・共通役牌・客風など複数の方式があり、統一ルールではないことを確認。
