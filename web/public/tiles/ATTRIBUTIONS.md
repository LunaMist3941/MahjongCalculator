# Tile artwork attribution

The SVG tile illustrations in this directory are from [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles).

The upstream repository states that all assets are in the public domain and links to [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The files were downloaded from its `Regular` directory on 2026-09-02 and renamed to match this application's tile IDs.
